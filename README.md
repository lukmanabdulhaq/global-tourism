## What This Platform Does

A comprehensive tourism intelligence interface that helps travellers explore destinations, cultures, events, and travel plans — powered by AI-assisted guides and a rich component library.

- Destination explorer — browse countries with cultural insights
- AI travel guide — AI-powered recommendations for itineraries
- Cultural hub — music, food, museums, and community events
- Travel planner — personalised trip planning tools
- Real-time events — discover local events by destination

## Tech Stack

| Layer | Technology |
|---|---|
| Framework | Next.js 15, React, TypeScript |
| UI Components | Radix UI, shadcn/ui, Tailwind CSS |
| AI Integration | AI SDK (@ai-sdk/react) |
| Forms | React Hook Form, Zod validation |
| Deployment | Vercel Edge Network |

## Project Structure

```
├── cultures/       # Cultural insights by region
├── events/         # Live events explorer
├── explore/        # Destination discovery
├── food/           # Culinary guides
├── museums/        # Museum directory
├── music/          # Music and arts by culture

```
